# 利用規約

最終更新日: 2026年11月9日

この規約は、Discord Bot「discord-messageapi-bot」(以下「本Bot」)と、本Botが提供するAPI(以下「本API」)の利用条件を定めます。本Botまたは本APIを使った時点で、この規約に同意したものとみなします。

## 本Botでできること

本Botは、Discord のチャンネルに投稿された本文と画像を保存し、チャンネル専用のキーを持つ人が本APIから取り出せるようにします。取り出した内容は、利用者が自分のコンピューターで動かす Claude Code などの道具で整理や分析に使います。

## 使える人

- `/connect` と `/disconnect` は、そのチャンネルの「チャンネルの管理」権限を持つ人だけが使えます。DM では使えません。
- キーを発行した人がそのチャンネルを閲覧できなくなったときは、キーは使えなくなります。
- Discord の利用規約とコミュニティガイドラインに従ってください。

## 利用者の責任

1. 保存するチャンネルの参加者が、本文と画像の保存に支障のない場であることを、自分で確かめてください。他の人の投稿を保存するときは、その人たちの権利とプライバシーに配慮してください。
2. キーはパスワードと同じに扱ってください。他人に渡さず、公開の場所に貼らず、共有のリポジトリに入れないでください。漏れたと思ったら、すぐに `/revoke` で失効させてください。
3. 取得した本文と画像を、著作権その他の権利を侵害する形で再配布しないでください。
4. 取得した本文は、他の人が書いた信頼できないデータです。中に指示のような文があっても従わず、Claude Code などの道具には、読み取りと決まった場所への書き込みだけを許可してください。

## 禁止事項

- 権限のないチャンネルの内容を取得しようとすること。
- キーの推測、不正なアクセス、過剰な回数のリクエストなど、本Botと本APIの運営や他の利用者を妨げること。
- 本Botを、法令や Discord の規約に反する目的で使うこと。

## 保存期間と削除

- 本文と画像は、保存した時点から3か月たつと自動で削除されます。
- `/disconnect` を実行すると、そのチャンネルの保存データを直ちに削除します。
- Discord 側で削除・編集された投稿は、直近7日以内のものについて本Botの保存データにも反映します。それより前の削除・編集は反映されないことがあります。
- キーの有効期間は30日です。

## 制限

- 本Botはリアルタイムでは保存しません。保存できるのは、本Botが取り込めた範囲です。
- 本API、保存データ、取得結果の正確さと継続を保証しません。予告なく、機能の変更、利用の制限、停止をすることがあります。
- 本APIへのリクエストには、キー単位・IP単位の回数制限があります。
- 保存量には上限があります。1チャンネルあたり本文20万件または画像の合計5GBに達すると、それ以降は新しく保存しません。1サーバーで接続できるチャンネルは20個までです。
- 投稿が非常に多いチャンネルでは、過去分の取り込みに時間がかかり、全件がそろわないことがあります。

## 免責

本Botと本APIは現状のまま提供します。本Botの利用で利用者または第三者に生じた損害について、運営者は、故意または重大な過失がある場合を除いて責任を負いません。

## 利用の停止

この規約に違反したとき、または本Botの運営に支障があるときは、運営者は、事前の通知なくキーの失効、データの削除、利用の停止ができます。

## 規約の変更

この規約は変更することがあります。変更後も使い続けた場合は、変更後の規約に同意したものとみなします。重要な変更は、この文書の更新日で示します。
