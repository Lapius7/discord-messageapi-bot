# プライバシーポリシー

最終更新日: 2026年11月9日

Discord Bot「discord-messageapi-bot」(以下「本Bot」)が、どの情報を、何のために、どのくらいの期間保存するかを説明します。

## 保存する情報

`/connect` を実行したチャンネルについて、次の情報を保存します。

| 情報 | 内容 |
|---|---|
| メッセージ | 本文、投稿日時、メッセージID、投稿者のユーザーIDと表示名 |
| 画像 | チャンネルに添付された png / jpg / gif / webp の画像ファイル(1枚20MBまで) |
| チャンネル情報 | サーバーID、チャンネルID、`/connect` を実行した人のユーザーID |
| キー | キーのハッシュ(SHA-256)、発行者、有効期限、失効日時。キーそのものは保存しません |
| 操作の記録 | 日時、操作の種類(キーの発行・失効、データ削除など)、チャンネルID、操作した人。本文は記録しません |

`/connect` より前に投稿された内容も、チャンネルの履歴から取り込んで保存します。`/connect` を実行していないチャンネルの内容は保存しません。

## 利用目的

- 保存した本文と画像を、キーを持つ人が本APIから取得できるようにするため。
- 不正な利用を防ぎ、問題を調べるため(操作の記録とアクセス制限)。

広告や分析のために使うことはなく、第三者に販売もしません。

## 保存場所と提供先

- データは、運営者が管理するサーバーに保存します。
- 本APIの入口には Cloudflare を使うので、通信は Cloudflare を経由します。本文と画像は、通信の中継のためにのみ Cloudflare を通り、Cloudflare には保存しません。
- 本APIを呼び出せるのは、チャンネル専用のキーを持つ人だけです。キーを持つ人は、そのチャンネルの保存済みの本文・画像・投稿者名を取得できます。
- 法令に基づく開示の求めがあったときは、法令の範囲で対応します。

## 保存期間と削除

- 本文と画像は、保存した時点から3か月で自動的に削除します。
- `/disconnect` を実行すると、そのチャンネルの本文、画像、キーを直ちに削除します。
- 本Botがチャンネルを見られなくなったとき、またはキーの発行者がチャンネルを閲覧できなくなったときは、キーを失効します。保存済みの本文と画像は、3か月の期限まで残ります。
- Discord 側で削除・編集された投稿は、直近7日以内のものを保存データにも反映します。それより前の削除・編集は反映されないことがあります。
- 操作の記録は、保存期間を過ぎたあとも、不正の調査に必要な間は残すことがあります。

## 削除の依頼

自分の投稿の削除を希望する場合は、次のいずれかを行ってください。

- チャンネルの管理権限を持つ人に、`/disconnect` の実行を依頼する。
- 下記の連絡先に、サーバーIDとチャンネルID、削除したい投稿を伝える。

## 安全管理

- キーは、256ビットの乱数から作り、ハッシュだけを保存します。
- サーバーは外部から直接アクセスできないようにし、本Botの入口からの通信だけを受け付けます。画像は認証を通した場合のみ配信し、公開のURLでは配信しません。
- データベースには、必要最小限の権限だけを持つ専用のユーザーを使います。
- ただし、完全な安全を保証するものではありません。

## Discord が収集する情報

Discord 上の情報の扱いは、Discord のプライバシーポリシーに従います。本Botは、Discord が提供する Message Content Intent を使って本文を受け取ります。
